# Public candidate changes and status

This local candidate is a sanitised publication artifact. It is not a second independently governed project, and preparation does not authorise publication.

## Preserved design

The technical architecture retains sections 1–24, R01–R16, ADR01–ADR15, N01–N12, AC01–AC20 and D01–D16, with four Mermaid diagrams and the permission, recovery, cost and privacy controls. Status vocabulary remains AGREED, PROPOSED, UNVALIDATED and OPEN. Generic examples replace personal pilot names; requirements are not removed because their original setting was personal.

The reusable Python utilities, tests, thin adapters, record templates and skill metadata retain their source behaviour. The legacy manifest ID `owner_vision` points to generic product vision, not a personal profile. All public context references and hashes are regenerated. No private acceptance record or original Git commit is imported.

## Explicit differences

The main platform is intended to be public after approval. Private instance storage is outside it. Public issues describe only publishable platform engineering; private tasks, approvals, handoffs, memories and resource observations never become public merely because the platform is public. ADR16 proposes that boundary. The private workspace layout and any future loader remain proposals, not implemented storage or synchronisation services.

Private conversation identifiers, owner-specific provenance, machine paths, account data, private task histories and raw runtime evidence are excluded. Exact source-to-export traceability is retained privately. Public architecture IDs preserve technical traceability without distributing those records.

Exploration stays task-free. Actionable work remains task-bound. Machine receipts stay strict, complete coverage remains mandatory, missing or conflicting policy cannot PASS, and the handoff checker still requires complete records and an established outgoing stop. The local reader rejects source paths outside its workspace. It does not yet compose an external private instance.

Historical private runtime observations are not candidate compatibility evidence. Only local deterministic results described in the candidate audit are claimed. Native runtime discovery, external connectors, full platform compatibility, live quotas and autonomous dispatch remain unvalidated here.

## Approval still needed

The licence and attribution, public commit identity, public release review and any later publication require explicit decisions. No private predecessor or original history is superseded or modified by this export.
